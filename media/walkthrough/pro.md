## Pro tools

The Pro tools run inside a free 14-day trial that starts the first time you use one. The trial is recorded only on this computer and needs no account, key or network.

* **Compare DBC With Another File**: added, removed and changed messages, signals, nodes, value tables and attributes, each marked breaking, non-breaking or cosmetic, with Markdown, HTML and CSV reports.
* **Decode Trace With This DBC**: decode a whole candump log, CSV file or ASCII log into a table of signal values, with filters, statistics per signal and per message, and timing against the cycle time. Files of several hundred megabytes are read in pieces.
* **Show Graphical Bit Layout**, **Create DBC Documentation**, **Export Signals As CSV**, **Create DBC From Signal CSV** and **Create Workspace DBC Inventory**.

After the trial, a one-time licence key keeps Pro: Personal USD 29, Business USD 59 per user.
